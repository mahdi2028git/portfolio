# Portfolio — Mahdi

Bilingual personal portfolio (English + Farsi).

**Live demo (after enabling GitHub Pages):**  
https://mahdi2028git.github.io/portfolio/

## Features
- Clean modern dark design
- Full English / Farsi support with language switcher
- Proper RTL layout for Farsi
- Responsive
- Showcases my main projects (MediTailor, Modern Tailor, Imed Manager)

## How to enable GitHub Pages
1. Go to the repository **Settings → Pages**
2. Under **Source**, select **Deploy from a branch**
3. Choose branch `main` and folder `/ (root)`
4. Save — the site will be available in about a minute at the link above.
